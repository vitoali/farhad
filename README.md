# ساخت اندیکاتور

این مخزن چارچوب قابل‌تکرارِ ارزیابی استراتژی‌های Pine Script است.

## موتور بک‌تست

فایل [`strategies/backtest_engine.pine`](strategies/backtest_engine.pine) یک
`strategy` در Pine Script v6 است که مسئولیت‌های زیر را از منطق سیگنال جدا
می‌کند:

- محدوده تست: پیش‌فرض ۳۰ روز اخیر یا تاریخ شروع و پایان دستی
- اجرای سفارش روی بسته‌شدن کندل، بدون pyramiding
- استاپ‌لاس و تی‌پی ثابت از لحظه ورود
- فاصله ریسک به‌صورت درصد یا پیپ
- تی‌پی با نسبت ریسک‌به‌ریوارد، درصد یا پیپ
- انتخاب لانگ/شورت و خروج در انتهای بازه تست

برای استفاده، محتوی فایل را در Pine Editor تریدینگ‌ویو قرار دهید، ذخیره کنید و
روی هر نماد و تایم‌فریم جداگانه اجرا کنید. TradingView Strategy Tester ذاتاً
هر بار فقط معامله‌های نمادِ چارت فعلی را شبیه‌سازی می‌کند؛ بنابراین نتایج
BTC/USDT، HYPE/USDT، BEAT/USDT، EUR/USD و XAU/USD باید جداگانه ثبت و مقایسه
شوند.

## افزودن هر کد

هنگام دریافت هر اندیکاتور:

1. منطق و شرایط ورود/خروج آن را مستند می‌کنیم، از جمله تأییدشدن روی بسته‌شدن
   کندل و نبود repaint.
2. فقط بخش `SIGNAL ADAPTER` در موتور با دو خروجی boolean به نام‌های
   `longSignal` و `shortSignal` جایگزین می‌شود.
3. همان تنظیمات هزینه، اسلیپیج، بازه، تایم‌فریم و ریسک روی همه گزینه‌ها اعمال
   و نتایج ثبت می‌شود.
4. برنده‌ها روی بازه‌ای جدا از بازه انتخاب ارزیابی می‌شوند تا از بیش‌برازش
   جلوگیری شود.

## تنظیمات ابتدایی

- کریپتو: `Risk unit = Percent` و SL قابل انتخاب ۱٪ یا ۳٪.
- فارکس: `Risk unit = Pips` و SL قابل انتخاب ۳ یا ۵ پیپ. مقدار `One pip in
  price units` را طبق نماد و بروکر تنظیم کنید؛ برای EURUSD معمولاً `0.0001`
  است. برای XAUUSD این مقدار بین فیدهای مختلف یکسان نیست.
- TP هنوز به‌صورت قطعی تعیین نشده؛ موتور از RR پیش‌فرض ۱.۵ استفاده می‌کند و
  آن را به‌صورت ورودی قابل تغییر نگه می‌دارد.

نتیجه یک ماه تنها برای غربال اولیه مناسب است. انتخاب نهایی باید علاوه بر
وین‌ریت، سود خالص پس از هزینه، Profit Factor، افت سرمایه و پایداری در
تایم‌فریم‌ها و داده‌های خارج از نمونه را در نظر بگیرد.
