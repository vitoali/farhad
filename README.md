# پروژه تحلیل و بک‌تست اندیکاتورهای Pine Script

سیستم تحلیل انتقادی و بک‌تست بیش از ۶۰ اندیکاتور/استراتژی TradingView با هدف نهایی ساخت یک استراتژی ترکیبی مقاوم.

## ساختار

- `docs/methodology.md` — چارچوب ثابت پروژه: نمادها، تایم‌فریم‌ها، مدل‌های ریسک، هزینه‌ها، قواعد ضدریپینت، متریک‌ها و پروتکل OOS.
- `docs/analysis-template.md` — قالب اجباری تحلیل هر کد.
- `analyses/` — تحلیل هر کد: `NNN-short-name.md`
- `codes/` — سورس Pine هر کد: `NNN-short-name.pine`
- `results/ledger.csv` — دفتر نتایج کمی (هر ردیف: کد × نماد × تایم‌فریم × مدل ریسک).
- `results/signals-schema.md` — فیچرهایی که برای هر سیگنال/محدوده ثبت می‌شوند.

## گردش کار

1. کد Pine (یا نتیجه بک‌تست) ارسال می‌شود.
2. کد در `codes/` ذخیره و تحلیل کامل طبق قالب در `analyses/` نوشته می‌شود.
3. نتایج کمی در `results/ledger.csv` ثبت می‌شوند.
4. اجزای تأییدشده (طبق معیارهای بخش ۹ متدولوژی) وارد استراتژی ترکیبی می‌شوند.
