# تحلیل دقیق استراتژی نقطه کور (Blind Spot)

## تعریف یک‌خطی
وقتی قیمت سطح را می‌شکند و به‌اندازهٔ یک رنج متوسط (TH/ATR/IDR) از آن دور می‌شود، در **پنجره زمانی بعدی** انتظار بازگشت به همان سطح (نقطه کور) دارید؛ چون ظرفیت حرکتی آن دوره عملاً مصرف شده است.

---

## نسخه ۱ — کلاسیک (معمولاً Daily)

| مرحله | قانون |
|------|--------|
| سطح | Open/Close یا سطح ساختار معتبر |
| شکست | Breakout واقعی (ترجیحاً لانگ‌بار نسبت به ATR) |
| فاصله | ≥ حدود ۱ Daily Range / ATR / TH |
| ورود | Limit روی ناحیه شکسته‌شده **فقط کندل بعد** |
| انقضا | اگر همان دوره تاچ نشد → حذف اردر |
| استاپ | پشت کندل یا باقیمانده تا ۱۰۰٪ رنج |
| تارگت | حدود ۱ تا ۲ رنج |

### مثال عددی ویدیو (GBPUSD Daily)
- رنج متوسط ≈ ۱۰۰ پیپ
- ورود روی ≈ ۸۰ پیپ فاصله → SL ≈ ۲۰ پیپ
- TP محافظه‌کار ≈ ۱۰۰ / تهاجمی ≈ ۲۰۰ پیپ

---

## نسخه ۲ — لایو (آپدیت برای تایم پایین‌تر)

| شرط | توضیح |
|-----|--------|
| کندل زنده | هنوز Close نشده |
| پرشدگی زودهنگام | LiveRange ≥ TH/ATR همان تایم |
| زمان باقی‌مانده | باید برای ریتریس وقت باشد |
| ناحیه | Open/Close کندل قبلی (گاهی شدو/هیدن) |
| اجرا | اسکالپ همان تایم یا تریگر تایم پایین‌تر |

### مثال ویدیو
- H4 طی ۲ ساعت اول رنج را پر می‌کند و ۲ ساعت مانده → انتظار پولبک به OC قبلی

---

## فرمول‌ها

```text
IDR  = SMA(High - Low, N)
ATR  = Average True Range(N)
TH   ≈ Price × 0.6666%     # توان حرکتی / گام بلند
گام کوتاه ≈ 0.8 × TH
```

داشبورد اندیکاتورهای آموزشی داخل ویدیو معمولاً سه عدد نشان می‌دهد:
1. TH
2. ATR / True Range میانگین
3. DR / رنج لایو کندل جاری

---

## اشتباهات رایج
- نگه داشتن اردر چند روز بعد از شکست (نقض قانون یک‌دوره‌ای)
- شکست ضعیف/ویک‌محور بدون فاصلهٔ یک‌رنجی
- نادیده گرفتن زمان باقی‌مانده در نسخه لایو
- سطح اشتباه تایم‌فریم (سطح M15 را با منطق Daily معامله کردن)

---

## منابع این پکیج

- ویدیو ۲: اجرای لایو روی پیوت/FTC و تایم تریگر (`L-y8sbh_a8U`)
- جزوه پرایس‌اکشن سعید خاکستر (ATR، مسترکندل، شکست، توان حرکتی)
