# Dice Bot 67

اتوماسیون دسکتاپ ویندوز برای بازی تاس تلگرام (گروه ۶۷).

برنامه با **PyAutoGUI** روی تلگرام دسکتاپ کلیک می‌کند:

1. یک‌بار روی 🎲  
2. بعد روی **SEND**  
3. صبر (۶۱–۱۰۰ ثانیه)  
4. یک‌بار روی 🎰  
5. بعد روی **SEND**  
6. تکرار…

## ویژگی‌ها

- فاصله زمانی تصادفی بین **۶۱ تا ۱۰۰** ثانیه  
- بعد از هر **۱۰ چرخه کامل** (🎲 + 🎰)، زمان جدید تصادفی انتخاب می‌شود  
- تأخیر تصادفی **۳ تا ۱۰** ثانیه قبل از SEND  
- جابه‌جایی تصادفی چندپیکسلی موس قبل از کلیک  
- کلید **F8** برای شروع / توقف  
- لاگ تعداد اجرا در `logs/dice_bot.log`  
- کالیبره مختصات + تشخیص اختیاری با OpenCV  

> فقط روی سیستم خودتان و با مسئولیت خودتان استفاده کنید. اتوماسیون ممکن است خلاف قوانین بازی یا تلگرام باشد و ریسک محدود شدن اکانت دارد.

## نصب (ویندوز)

```bat
cd dice-bot-67
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy config.example.json config.json
```

## کالیبره (مهم)

تلگرام دسکتاپ را باز کنید، وارد گروه بازی شوید طوری که 🎲 و 🎰 و دکمه SEND دیده شوند.

```bat
python main.py --calibrate
```

موس را به‌ترتیب روی 🎲، 🎰، SEND بگذارید و Enter بزنید.

اختیاری — برای پیدا کردن خودکار با تصویر:

```bat
python main.py --capture-templates
```

## اجرا

```bat
python main.py
```

سپس **F8** را بزنید تا شروع شود. دوباره F8 = توقف.

توقف اضطراری: موس را به **گوشه بالا-چپ** صفحه ببرید.

## ساخت فایل exe

```bat
build_exe.bat
```

خروجی: `dist\DiceBot67.exe`  
کنار exe یک `config.json` بگذارید (از روی `config.example.json`) و یک‌بار با `--calibrate` اجرا کنید:

```bat
DiceBot67.exe --calibrate
DiceBot67.exe
```

## تنظیمات مهم (`config.json`)

| کلید | معنی | پیش‌فرض |
|------|------|---------|
| `min_delay_sec` / `max_delay_sec` | بازه صبر بین اکشن‌ها | 61–100 |
| `delay_change_every_cycles` | هر چند چرخه زمان عوض شود | 10 |
| `send_delay_min_sec` / `max` | تأخیر قبل از SEND | 3–10 |
| `positions.dice/slot/send` | مختصات کلیک | بعد از کالیبره |
| `use_opencv` | پیدا کردن با تصویر | true |
| `hotkey_toggle` | کلید شروع/توقف | f8 |

## ساختار چرخه

```
🎲 → SEND → صبر(T) → 🎰 → SEND → صبر(T)   ⟵ یک چرخه
... این کار ۱۰ بار با همان T ...
T جدید تصادفی بین 61..100
```
