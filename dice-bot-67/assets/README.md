# قالب‌های تصویری (اختیاری)

اگر می‌خواهید برنامه خودش 🎲 / 🎰 / SEND را روی صفحه پیدا کند:

1. اول کالیبره کنید: `python main.py --calibrate`
2. بعد قالب بگیرید: `python main.py --capture-templates`

فایل‌های `dice.png` و `slot.png` و `send.png` اینجا ساخته می‌شوند.

اگر قالب نباشد، از مختصات ثابت داخل `config.json` استفاده می‌شود.
