# موتور بک‌تست آفلاین

## اجزا

- `data.py` — دانلود OHLCV: کریپتو از Gate.io (بایننس/بای‌بیت از این سرور مسدود است)، فارکس/طلا از یاهو (طلا = فیوچرز GC پراکسی XAU). خروجی در `data/<SYMBOL>_<TF>.csv` (زمان‌ها UTC، اپوک ثانیه، زمانِ باز شدن کندل). ۳۰۰ کندل گرم‌شدن قبل از پنجره آزمون اضافه می‌شود.
- `indicators.py` — پورت پایتونی کدهای Pine با حفظ منطق (001 UT Bot، 002 AlphaTrend با فیلتر تناوب، 003 MA Cross). همه سیگنال‌ها معادل «تأیید در کلوز کندل»اند.
- `engine.py` — اجرای معاملات: فیل در اوپن کندل بعد از سیگنال؛ SL/TP ثابت (اگر هر دو در یک کندل، SL اول — محافظه‌کارانه)؛ حالت فلیپ بومی؛ هزینه‌ها طبق متدولوژی (کریپتو ۰٫۲٪ رفت‌وبرگشت، EURUSD معادل ۱٫۱ پیپ، XAU معادل ۴٫۵ پوینت‌دهم).
- `run.py` — اجرای همه ترکیب‌ها (کد × نماد × تایم‌فریم × مدل ریسک) و نوشتن `results/ledger.csv` و لاگ معاملات با فیچرها در `results/trades/`.

## اجرا

```bash
pip install pandas numpy
python3 backtest/data.py   # دانلود/به‌روزرسانی داده
python3 backtest/run.py    # اجرای بک‌تست‌ها (از داخل پوشه backtest)
```

## افزودن کد جدید

1. تابع سیگنال را به `indicators.py` اضافه کن (خروجی: DataFrame با ستون‌های بولی `long` و `short` هم‌اندیس با داده).
2. در `run.py` به `signals_for` و لیست `codes` اضافه کن.
