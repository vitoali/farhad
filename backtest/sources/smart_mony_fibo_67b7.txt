// 📌 𝙄𝙉𝘿𝙄𝘾𝘼𝙏𝙊𝙍 𝘾𝘼𝙇𝘾𝙐𝙇𝘼𝙏𝙄𝙊𝙉𝙎
// --------------------------------------------------------------------------------------------------------------------{

pvtHi = ta.pivothigh(high, pivotLen, pivotLen)
pvtLo = ta.pivotlow(low,   pivotLen, pivotLen)

var float lastSwingHigh    = na
var float lastSwingLow     = na
var int   lastSwingHighBar = na
var int   lastSwingLowBar  = na

var float prevSwingHigh    = na
var float prevSwingLow     = na

var int   trendState       = 0

var float fibAnchorHigh    = na
var float fibAnchorLow     = na
var int   fibAnchorHighBar = na
var int   fibAnchorLowBar  = na

if not na(pvtHi)
    prevSwingHigh    := lastSwingHigh
    lastSwingHigh    := pvtHi
    lastSwingHighBar := bar_index - pivotLen

if not na(pvtLo)
    prevSwingLow    := lastSwingLow
    lastSwingLow    := pvtLo
    lastSwingLowBar := bar_index - pivotLen

// Trend shift detection
var bool bullShift = false
var bool bearShift = false

bullShift := false
bearShift := false

if not na(pvtHi) and not na(prevSwingHigh)
    if pvtHi > prevSwingHigh and trendState <= 0
        bullShift        := true
        trendState       := 1
        fibAnchorLow     := lastSwingLow
        fibAnchorLowBar  := lastSwingLowBar
        fibAnchorHigh    := pvtHi
        fibAnchorHighBar := bar_index - pivotLen

if not na(pvtLo) and not na(prevSwingLow)
    if pvtLo < prevSwingLow and trendState >= 0
        bearShift        := true
        trendState       := -1
        fibAnchorHigh    := lastSwingHigh
        fibAnchorHighBar := lastSwingHighBar
        fibAnchorLow     := pvtLo
        fibAnchorLowBar  := bar_index - pivotLen
