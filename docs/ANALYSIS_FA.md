# تحلیل وین‌ریت اندیکاتورها + Cardwell Hybrid Improved

## محدوده بک‌تست
- نمادها: **BTC-USD**، **Gold (GC=F ≈ XAU)**، **EURUSD**
- تایم‌فریم‌ها: `5m` / `15m` / `1h` / `4h`
- دوره: حدود ۲–۳ ماه اخیر (برای `5m/15m` محدودیت Yahoo ≈ ۶۰ روز؛ برای `1h/4h` ≈ ۹۰ روز)
- قوانین ریسک درخواستی:
  - BTC: SL **۳٪** / TP **۵٪**
  - بقیه: SL **۵ پیپ** / TP **۵ پیپ**
    - EURUSD: pip = `0.0001`
    - XAU با pip=`0.01` تقریباً بی‌معنی است (تقریباً همه تریدها در ۱ کندل بسته می‌شوند) → برای مقایسه عملی، حساسیت با pip=`1.0` هم گزارش شده

خروجی پس از برخورد به SL/TP بسته می‌شود و جستجو برای سیگنال بعدی از کندل بعد ادامه می‌یابد.

## نقاط قوت / ضعف

### Cardwell (اصلی)
- **قوت:** رژیم RSI+MA روی رونددارها (به‌خصوص BTC 1h/4h و EURUSD 15m) منطقی است؛ ساختار رژیم واضح.
- **ضعف ۱:** روی 5m/15m فلیپ سریع long↔short (همان مشکل «لانگ می‌ده بعد یهو می‌کنه»).
- **ضعف ۲:** سطح‌های SL/TP فقط بصری‌اند؛ بعد از برخورد هم «سیگنال باز» می‌ماند و اسکن پوزیشن واقعی ندارد.
- **ضعف ۳:** فیلترهای ADX/HTF پیش‌فرض خاموش‌اند → نویز زیاد در رنج.

### MACD (CM Ult MTF)
- **قوت:** تأیید جهت مومنتوم شفاف؛ روی EURUSD 5m بهترین وین‌ریت پایه (~۴۹٪).
- **ضعف:** با SL/TP درصدی BTC خیلی زود استاپ می‌خورد؛ سیگنال زیاد و نویزی روی LTF.

### EWO + RSI (Pridarasx)
- **قوت:** anti-flip عالی، فیلتر exhaustion + breakout، سیگنال کمتر و تمیزتر.
- **ضعف:** روی بعضی بازارها/تایم‌فریم‌ها سیگنال خیلی کم؛ وابسته به Volume/MFI.

### Elliott Wave (LuxAlgo) — پروکسی ZigZag
- **قوت:** تأیید ساختار سوئینگ؛ فلیپ کمتر از Cardwell روی HTF.
- **ضعف:** تأخیر تأیید پیوت؛ برای اسکالپ 5m دیر است؛ پیاده‌سازی موج کامل برای بک‌تست ساده نشد و ZigZag به‌عنوان پروکسی استفاده شد.

## Cardwell Hybrid Improved — چه چیزهایی قرض گرفته شد؟

| ضعف Cardwell | قرض از | راه‌حل در Hybrid |
|--------------|--------|------------------|
| فلیپ سریع LTF | EWO_RSI | cooldown `Min Bars Before Opposite` + one-per-leg کوتاه |
| سیگنال در رنج/نویز | Cardwell ADX (خاموش بود) + MACD | ADX و MACD direction پیش‌فرض روشن |
| ورود بدون مومنتوم | EWO | فیلتر چرخش EWO |
| فلیپ خلاف روند بزرگ‌تر | — | HTF Regime Confirmation پیش‌فرض روشن برای LTF |
| سیگنال بعد از SL/TP هنوز باز | — | **state machine**: تا SL/TP قفل؛ بعد از برخورد close + پاک‌کردن خطوط + ادامه اسکن |
