## فرمول FTC (تقریبی — فصل ۱۲ جزوه)

```
باکس = از نوک پیوت تا کندل پوشاننده
FTC_mid = میانه باکس (ترکیب با close + ATR پترن)
FTC_zone = mid ± 33% ارتفاع باکس

قابل استناد:
  نزولی: high پوشاننده > گره قبل از مستر AND close زیر بدنه مستر
  صعودی: low پوشاننده < گره قبل از مستر AND close بالای بدنه مستر
```

## امتیاز سطح

```
امتیاز اولیه = اهمیت TF×20 + FTC معتبر×25 + نوع کندل
امتیاز زنده  = اولیه − تاچ×8 + (اگر شکسته: تاچ×12) + پرتاب/ATR×4
```

قبل از شکست: **تاچ بیشتر = ارزش کمتر** (فصل ۴ خاکستر)
