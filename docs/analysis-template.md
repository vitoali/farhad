## ۱. منطق دقیق کد

توضیح گام‌به‌گام شرایط تولید سیگنال/محدوده با ارجاع به خطوط کد. تعریف دقیق شرط تشکیل، شرط بی‌اعتباری، و شرط حذف/تغییر اشیا.

## ۲. بررسی فنی Pine Script

- **Repaint:** دارد/ندارد + مکانیزم دقیق (حذف اشیا، `security` بدون تثبیت، استفاده از بار جاری و...)
- **Lookahead:** دارد/ندارد + خطوط مربوطه
- **تأخیر تثبیت:** (مثلاً pivot با `r` کندل تأخیر)
- **خطاهای محاسباتی/محدودیت‌ها:** (سقف تعداد اشیا، `max_bars_back`، رفتار در گپ، تقسیم بر صفر و...)
- **حکم فنی:** قابل‌بک‌تست مستقیم / نیازمند نسخه اصلاح‌شده / رد

## ۳. تعریف قابل‌بک‌تست

- **موفقیت:** (مثلاً: پس از نخستین لمس محدوده، رسیدن به TP قبل از SL)
- **بی‌اعتباری:** (مثلاً: بسته‌شدن کندل کامل آن‌سوی محدوده قبل از لمس معتبر)
- **لمس معتبر:** تعریف صریح برخورد
- **ورود، SL، TP:** قیمت و زمان دقیق هر کدام
