# منابع کتاب — اولویت مرجع

## ۱. انگلیسی (مرجع اصلی منطق شناسایی)

**Steve Nison — *Japanese Candlestick Charting Techniques***

- تعریف دقیق الگوها، آستانه‌ها و استثناها
- فصل‌های ۳ تا ۸: ساختار کندل، معکوس‌ساز، ستاره‌ها، تداوم، دوجی
- تمام قوانین در `pine/nison_candlestick_patterns.pine` بر اساس این نسخه است

### قوانین کلیدی پیاده‌سازی‌شده (فصل ۴)

| الگو | قانون نیسون |
|------|-------------|
| Engulfing | فقط بدنه اصلی؛ اگر کندل اول شبیه دوجی باشد رنگ مهم نیست |
| Dark Cloud | باز شدن بالای High قبلی؛ بسته شدن زیر وسط بدنه سفید |
| Piercing | باز شدن زیر Low قبلی؛ بسته شدن بالای وسط بدنه مشکی |
| On-neck / In-neck / Thrusting | تفاوت در عمق بسته شدن کندل سفید نسبت به کندل مشکی |

## ۳. دو‌زبانه خلاصه (۱۲۶ صفحه)

نسخه دوم لینک Google Drive — فارسی + انگلیسی در کنار هم

- **کاربرد:** فهم بهتر، نکات توضیحی، واژه‌های فارسی در کنار اصطلاح انگلیسی
- **نه** مرجع قانون — نسخه abridged است
- مثال: «الگوی فراگیر» = Engulfing، «پوشش ابر سیاه» = Dark Cloud Cover
