## نحوه تأیید روی چارت

1. `KhaksterTrexAtrLib` را Publish کنید
2. `trex_atr_panel.pine` را Add کنید (`import` را با نام کاربری خودتان عوض کنید)
3. نماد **AUDDKK** — تایم **H1**
4. در تنظیمات پنل: **Calibration ref = MT5**
5. ستون آخر باید نزدیک TH/TR مرجع باشد
6. اگر TR کلی پایین‌تر/بالاتر است → **Pip scale** را تنظیم کنید
