|---------|-----|

## فرمول درست ارتقا (روی اسکلت ICT22)

1. **هدف نقدینگی شناور:** رنج سشن وقتی تمام شد قفل می‌شود؛ سشن بعدی همان را سوئیپ می‌کند.  
2. **تاییدیه حفظ می‌شود:** SMT (اختیاری) → CHoCH پنج‌دقیقه → OTE → بعد تریگر.  
3. **تریگر دوگانه:** اول M5 (Disp+FVG روی ۵دقیقه)، اگر نبود M1. فقط یک پوزیشن.  
4. چارت پایه همچنان **M1**.
