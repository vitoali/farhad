# بک‌تست Strong SD Magnet

دوره: ~۲–۳ ماه اخیر | نمادها: BTC / EURUSD / XAU | TF: 5m, 15m, 1h, 4h

## سیگنال‌های تست‌شده
| حالت | معنی |
|------|------|
| **magnet** | ریتست زون قوی → معامله به سمت زون مخالف (منطق اصلی اندیکاتور) |
| **bounce** | لمس زون قوی → معامله در جهت مخالف زون (Demand→Long / Supply→Short) |
| **native exit** | SL پشت زون، TP روی mid زون هدف |
| **atr_hiWR** | SL=2×ATR / TP=1×ATR |
| **pip5 / pct** | قوانین قبلی کاربر |

### قوانین کاربر (ضعیف برای این اندیکاتور)
- BTC magnet + SL3%/TP5%: WR ≈ **۸–۱۰٪** (بیشتر timeout/استاپ)
- EURUSD magnet + ۵ پیپ: WR ≈ **۴۵–۵۰٪** روی 5m
- XAU magnet + ۵ پیپ (pip=1): WR ≈ **۴۲–۴۵٪** روی 5m/15m

## جمع‌بندی
1. **Magnet native** به‌تنهایی وین‌ریت پایینی دارد چون TP تا زون مخالف دور است.
2. بهترین عملکرد عملی: **Magnet یا Bounce روی زون قوی (≥6.5) + خروج ATR (ترجیحاً SL پهن‌تر از TP برای WR)**.
3. روی **4h** تقریباً magnet شلیک نمی‌شود (زون مخالف هم‌سشن کمیاب است)؛ bounce بهتر کار می‌کند.
4. قوانین Percent 3/5 برای BTC با این سیگنال‌ها مناسب نیست.
